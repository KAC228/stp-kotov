# Выгрузка сайта на reg.ru (повторная, без поломок)

Сайт — **статический экспорт** Next.js. На хостинг попадает только папка **`out`** после сборки.  
Node.js на сервере **не нужен**. Заявки уходят через **`send.php`** (PHP + ВКонтакте).

---

## 1. Подготовка на компьютере

Откройте терминал в папке `ksd-site`:

```powershell
cd "C:\Users\Михаил\OneDrive\Desktop\КСД Илья\ksd-site"
npm install
npm run build
```

Или одной командой (сборка + zip-архив):

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\prepare-deploy.ps1
```

После сборки проверьте, что есть:

| Путь в `out` | Зачем |
|--------------|--------|
| `index.html` | Главная |
| `partnership.html`, `contacts.html`, … | Страницы |
| `_next/` | Скрипты и стили (обязательно целиком) |
| `send.php` | Формы → сообщения сообщества ВК |
| `send.config.php.example` | Шаблон конфигурации (токены — на сервере) |
| `pay.php` | Init оплаты T‑Bank → PaymentURL |
| `tbank-notify.php` | Webhook статусов оплаты (NotificationURL) |
| `pay.config.php.example` | Шаблон TerminalKey / Password (секреты — на сервере) |
| `lib/tbank.php` | Подпись Token и вызов Init |
| `.htaccess` | Чистые URL и 404 |
| `images/` | Картинки, логотип, `og-image.jpg` (1200×630 для соцсетей) |
| `robots.txt`, `sitemap.xml` | SEO |

**На сервер НЕ заливать:** `node_modules`, `.env.local`, исходники `app/`, `components/`, папку `out` как вложенную папку.

---

## 2. Куда заливать на reg.ru

Обычно корень сайта — одна из папок (смотрите в панели «Хостинг» → «Файловый менеджер»):

- `www/`
- `public_html/`
- `стп-котов.рф/` (папка домена)

В **корень домена** должны лежать `index.html`, `send.php`, папка `_next` — **рядом**, не внутри подпапки `out`.

Домен в проекте: **стп-котов.рф** (`SITE_URL` в `constants/brand.ts`).

## 3. Повторная выгрузка (чтобы не сломалось)

### Перед заливкой

1. **Скачайте с сервера копию `send.php`** (если на хостинге правили токен/чат вручную).
2. По желанию — полный бэкап корня сайта (zip в файловом менеджере reg.ru).

### Порядок заливки (важно)

| Шаг | Действие |
|-----|----------|
| 1 | Удалить на сервере **только папку `_next`** (старые JS-файлы иначе дают белый экран / ошибки в консоли). |
| 2 | Залить **новую папку `_next`** из `out` целиком. |
| 3 | Залить **все `.html`** из `out` (перезаписать): `index.html`, `partnership.html`, `contacts.html`, … |
| 4 | Залить `404.html`, `robots.txt`, `sitemap.xml`, `.htaccess`. |
| 5 | Залить папку **`images`** (перезаписать при изменениях). |
| 6 | **`send.php`**: перезаписать из `out`. |
| 7 | **`send.config.php`**: на сервере создать из `send.config.php.example`, указать токен бота и chat_id (файл **не** в git и **не** в zip-архиве). |
| 8 | **`pay.php`**, **`tbank-notify.php`**, **`lib/tbank.php`**: залить из `out`. |
| 9 | **`pay.config.php`**: на сервере создать из `pay.config.php.example` — TerminalKey, Password, Success/Fail/Notification URL. |

### Чего не делать

- Не удалять весь сайт, если не уверены — достаточно обновить `_next` + html.
- Не заливать папку `out` как подкаталог (`public_html/out/index.html` — сайт не откроется).
- Не оставлять старую `_next` рядом с новой (имена чанков меняются каждую сборку).

### После заливки

1. Открыть в **режиме инкогнито**: `https://стп-котов.рф/`
2. Проверить: главная, `/partnership`, `/contacts`, якорь `/#configurator`
3. Отправить тестовую заявку (партнёрство / контакты) — сообщение в ВК админу
4. F12 → вкладка Network: нет красных 404 на файлы в `_next/`

## 4. FTP / файловый менеджер

**FileZilla / WinSCP:**

- Хост: из панели reg.ru (часто `serverXX.hosting.reg.ru` или FTP-доступ к домену)
- Логин / пароль: «FTP-пользователи» в панели
- Режим: **перезапись** файлов, для `_next` — «всегда перезаписывать»

**Файловый менеджер reg.ru:**

1. Хостинг → Файловый менеджер → корень домена  
2. Загрузить файлы из `out` (можно zip → распаковать **в корень**, не в подпапку)

---

## 5. SSL и домен

- В reg.ru: домен привязан к хостингу, SSL (Let's Encrypt) включён.
- После SSL можно в `.htaccess` раскомментировать редирект на HTTPS (см. `public/.htaccess`).

## 6. Если что-то не работает

| Симптом | Решение |
|---------|---------|
| Белая страница, ошибки в консоли про `.js` | Удалить старую `_next`, залить новую целиком |
| `/partnership` — 404 | Залить `.htaccess` и `partnership.html` |
| Формы не отправляются | Проверить `send.php` и `send.config.php` в корне, PHP включён на тарифе |
| Оплата не открывается | Проверить `pay.php`, `pay.config.php`, Origin домена, TerminalKey/Password |
| Нет webhook об оплате | NotificationURL в ЛК = `/tbank-notify.php`, файл залит, ответ `OK` |
| Старая версия сайта | Ctrl+F5 или очистить кэш CDN в панели reg.ru |
| Кракозябры | Кодировка файлов UTF-8 без BOM |

## 7. Краткая шпаргалка

```
npm run build
→ открыть ksd-site\out
→ FTP: корень домена
→ удалить _next на сервере
→ залить всё из out (содержимое, не папку out)
→ сохранить/проверить send.php
→ создать send.config.php на сервере (из send.config.php.example)
→ создать pay.config.php на сервере (из pay.config.php.example)
→ в ЛК T‑Bank NotificationURL = https://<домен>/tbank-notify.php
→ проверить сайт в инкогнито
```

Токены ВК хранятся в **`send.config.php` на сервере** — файл в `.gitignore`, не коммитить и не класть в публичные архивы. При утечке токена — перевыпустить в настройках сообщества (Работа с API).

Ключи эквайринга T‑Bank — в **`pay.config.php` на сервере** (тоже не в git / не в zip). Чек-лист теста оплаты: [`docs/PAYMENT-TBANK-TEST.md`](docs/PAYMENT-TBANK-TEST.md).

Подтверждение оплаты: только **Notification (Token)** и **GetState** (`pay-status.php`). Страница `/success` без `PaymentId` / без ответа банка «оплачено» не считается успехом.

## 8. Оплата T‑Bank (карта + СБП)

1. В ЛК интернет-эквайринга: терминал, способы **карта** и **СБП**, онлайн-касса для автоматических чеков.
2. На сервере: `pay.config.php` с `terminal_key`, `password`, `taxation` / `tax` под вашу систему налогообложения.
3. `notification_url` в конфиге и в ЛК: `https://стп-котов.рф/tbank-notify.php` (или ваш домен).
4. Физлицо в форме заказа с картой/СБП уходит на `PaymentURL` банка (**без** заявки в ВК). Юрлицо / счёт — по-прежнему заявка в ВК.
5. Тестовый товар **1 ₽** в каталоге — см. `docs/PAYMENT-TBANK-TEST.md` (СБП от 10 ₽).
6. `pay.config.php` заливать на сервер **вручную** (не в zip): TerminalKey + Password.
