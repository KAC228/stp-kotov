**Не является юридической консультацией.**

## Сторонние SDK / сервисы

| Сервис | Назначение | Когда |
|--------|------------|-------|
| Яндекс.Метрика (+ вебвизор) | Аналитика | Только после согласия cookie |
| АО «ТБанк» | Оплата, чек | При оплате заказа |
| VK API | Уведомления о заявках | При отправке форм |
| Google Fonts (Inter) | Шрифт | При загрузке страницы (next/font) |

## Что остаётся вручную

1. Подать уведомление в РКН по черновику.
2. Подтвердить права на все фото/логотипы партнёров.
3. Если появятся email-рассылки — добавить unsubscribe в каждое письмо.
