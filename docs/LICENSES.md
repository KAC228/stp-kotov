# Шрифты и изображения

## Шрифты

| Шрифт | Источник | Лицензия |
|-------|----------|----------|
| Inter | `next/font/google` | SIL Open Font License 1.1 |

Закомментированные `@font-face` (Zenter SP, Lozung Caps) в `globals.css` **не подключены** к продакшену, пока файлы не добавлены в `/public/fonts/` с подтверждённой лицензией.

## Изображения и логотипы

| Актив | Примечание |
|-------|------------|
| `/images/logo.svg`, бренд СТП-КОТОВ | Собственность оператора |
| `/images/partners/*` | Логотипы партнёров (Формфактор, Fliben, Magnetic Light) — использование в разделе «Наши партнёры» по согласованию с партнёрами |
| Фото проектов / монтажа / сертификатов | Материалы СТП-КОТОВ или предоставленные для публикации |
| Скриншоты / scraped HTML в `data/` | Служебные, не публикуются в `out/` |

Перед коммерческим использованием сторонних фото убедитесь в наличии прав или лицензии.
