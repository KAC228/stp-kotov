# Проверка оплаты T‑Bank

## Перед тестом

1. В ЛК Т‑Бизнес: терминал с **картой** и **СБП**, подключена онлайн-касса.
2. На хостинге создать `pay.config.php` из `pay.config.php.example` (TerminalKey, Password, URL).
3. В ЛК терминала NotificationURL: `https://<домен>/tbank-notify.php` (или то же значение в `pay.config.php`).

## Карта / СБП (11 ₽)

1. Каталог → «Тестовая оплата T‑Bank (11 ₽)» → в корзину  
   (`/catalog/test-oplata-tbank-11-rub-TEST-11RUB`).
2. Оформить заказ (физлицо), способ **Банковская карта** или **СБП**, email для чека.
3. Редирект на форму T‑Bank → оплатить.
4. Ожидаемо: `/success?PaymentId=…`, статус только через `pay-status.php` → GetState. Чек — с онлайн-кассы на email.

Минимум СБП у T‑Bank — **10 ₽**, поэтому тест стоит **11 ₽**.

## После проверки

- Убедиться, что в `pay.config.php` боевой терминал.
- Пересобрать **без** `NEXT_PUBLIC_TBANK_TEST_SKU` и залить `out`, чтобы убрать тестовый товар.
