# Проверка оплаты T‑Bank

## Перед тестом

1. В ЛК Т‑Бизнес: тестовый терминал, включены **карта** и **СБП**, подключена онлайн-касса.
2. На хостинге создать `pay.config.php` из `pay.config.php.example` (TerminalKey, Password, URL).
3. В ЛК терминала NotificationURL: `https://<домен>/tbank-notify.php` (или то же значение в `pay.config.php`).

## Карта (1 ₽)

1. Каталог → «Тестовая оплата T‑Bank (1 ₽)» → в корзину.
2. Оформить заказ (физлицо), способ **Банковская карта**, email для чека.
3. Редирект на форму T‑Bank → оплатить тестовой картой из ЛК.
4. Ожидаемо: редирект на `/success?PaymentId=…`, статус **только** через `pay-status.php` → GetState у T‑Bank. Сам заход на `/success` оплату не подтверждает. Чек — с онлайн-кассы на email.

## СБП (от 10 ₽)

Минимум СБП у T‑Bank — **10 ₽**. Товар за 1 ₽ для СБП не подойдёт.

Варианты:

- добавить в корзину обычные позиции на сумму ≥ 10 ₽, или
- временно в [`constants/tbank-test-product.ts`](../constants/tbank-test-product.ts) поставить `priceRub: 10`.

Дальше тот же сценарий, способ **СБП / QR-код** (на форме банка выбирается СБП).

## После проверки

- Переключить `pay.config.php` на **боевой** терминал.
- Убрать тестовый SKU из [`lib/fliben-products.ts`](../lib/fliben-products.ts) (строка с `TBANK_TEST_PRODUCT`) или удалить файл константы.
